🌍 Aethelion Planet – Imaginary Travel Experience

Aethelion Planet is a creative web-based project that simulates a fictional space travel experience, where users can explore a designed planet as if booking a trip through a travel agency.
The platform focuses on storytelling, imagination, and immersive UI design, allowing users to experience a completely fictional world with structured features and visual exploration.

✨ Features
- Interactive imaginary planet travel experience
- Travel-agency-inspired journey interface
- Unique fictional planet characteristics
- Dedicated gallery showcasing planet visuals
- Immersive UI focused on storytelling
- Responsive design for different devices
